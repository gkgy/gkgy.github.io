--- layout: page title: 发布文章 permalink: /publish/ nav: publish eyebrow: PUBLISH description: "在本站登录后，直接写作、修改和发布文章。" --- 这是博客的写作入口。点击下面的按钮，在本站登录一次，就可以新建、修改和删除文章，不需要再来回打开 GitHub。

进入博客后台 →

进入后台后： - 点击 **新建文章**，填写标题、日期、标签和正文； - 点击 **发布**，文章通常会在一两分钟后出现在首页； - 打开已有文章，可以继续编辑或删除。 后台仍然使用你的 GitHub 账号确认身份，但登录和写作都在本站完成。访客即使打开后台，也没有权限修改文章。 ## 备用入口 如果博客后台临时不可用，仍可从 GitHub 备用入口发布文章。
